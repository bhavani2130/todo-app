# Todo App (MERN Stack)

## 📌 Project Description
A simple full-stack To-Do application built using React, Node.js, Express, and MongoDB.

## 🚀 Features
- Add tasks
- Edit tasks
- Delete tasks
- View all tasks
- REST API integration

## 🛠 Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB

## ▶ How to run
### Backend
npm install 
node todo-node.js

### Frontend
npm install
npm run dev
